Version 1.0.0 – Das erste Release

Git ohne Terminal

  • Repositorys: Ordner öffnen, zuletzt geöffnete, Klonen per URL mit Fortschritt, neues Repository mit README und .gitignore-Vorlage.
  • Änderungen: Nicht vorgemerkt und vorgemerkt, ganze Dateien, einzelne Abschnitte oder einzelne Zeilen vormerken, Änderungen verwerfen (neue Dateien in den Papierkorb).
  • Diff: Nebeneinander oder untereinander, mit Syntaxfarben; Bilder als Vorher/Nachher.
  • Commit: Zusammenfassung und Beschreibung, letzten Commit ändern (Amend), Co-Autoren.
  • Verlauf: Branch-Grafik, Commit-Details, Datei-Verlauf auch über Umbenennungen, Suche nach Nachricht, Autor und Hash; Cherry-Pick, Revert und Zurücksetzen.

Branches und Server

  • Branches: anlegen, wechseln (Änderungen auf Wunsch stashen), umbenennen, löschen, zusammenführen.
  • Konflikte: farbig zeigen, „meine“ oder „deren“ Version wählen oder in Textline öffnen, dann abschließen oder abbrechen.
  • Abrufen, Pull und Push mit Fortschritt; Branches veröffentlichen, auf dem Server löschen.
  • Anmeldung über den Git Credential Manager des Systems. Gitline speichert keine Passwörter oder Tokens.
  • Stash, Tags und .gitignore-Helfer mit Vorlagen.
  • Englisch und Deutsch, hell und dunkel, eigene Akzentfarbe und der optionale Stil Acryl. Unter Windows „Mit Gitline öffnen“ im Kontextmenü von Ordnern.
