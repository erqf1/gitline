How it works

Three steps, no commands.

Gitline uses the Git that is already on your computer and puts a calm, clear face on it.

01

Open a project

Open a folder, clone a project from GitHub or GitLab by its address, or start a new repository. On Windows, right-click a folder and choose “Open with Gitline”.

02

See and pick changes

Every changed file with its lines in color. Stage whole files, single sections or even single lines for the next commit.

03

Commit and push

Write a short summary, press Commit, then Push. Gitline shows how many commits are waiting and tells you in plain words if the server has newer ones.

Your sign-in stays with your system

Gitline never sees or stores passwords or tokens. Signing in to GitHub or GitLab goes through the Git Credential Manager of your system, the same one the terminal uses.

Hard to break things

Anything that throws work away asks first. Discarded new files go to the trash, and when switching branches would overwrite changes, Gitline offers to stash them.

FAQ

Questions

Is it really free?

Yes. Gitline is open source under the Apache 2.0 license, with no account, no ads and no tracking.

Do I need to install Git?

Yes, Gitline uses the Git on your computer, so it behaves exactly like Git in the terminal. If Git is missing, Gitline says so and links to the download.

Where do my passwords go?

Not to Gitline. It never asks for, sees or stores passwords or tokens. When a server wants you to sign in, Git asks the credential manager of your system, which shows its own window. On Windows that comes with Git for Windows.

Does it work with GitHub, GitLab and others?

Yes. Gitline talks to any server Git can reach, over HTTPS or SSH: GitHub, GitLab, Codeberg, Bitbucket or your own.

Can I break my project?

Everything that throws work away asks first, and discarded new files go to the trash. Gitline only runs normal Git commands, so you can always continue in the terminal.

What happens with conflicts?

Gitline lists the files, colors both versions and lets you keep yours, take theirs or edit the file, for example in Textline. When everything is solved, one click finishes the merge. You can always abort.

Which languages does the app speak?

English and German. It follows your system language and can be changed in the settings.
